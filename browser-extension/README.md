# Ценоскоп 0.6 — автоматический обход → JSON

Расширение Chrome/Edge обходит заданный список карточек Ozon/Wildberries и сохраняет результат в JSON. Сервер, сайт, API и токены для этого не нужны.

## Установка и запуск

1. Распакуйте `cenoskop-collector-v0.6.0.zip` в отдельную папку.
2. Откройте `chrome://extensions` или `edge://extensions`, включите режим разработчика, выберите «Загрузить распакованное расширение» и папку с `manifest.json`.
3. При обновлении замените файлы в ранее установленной папке и нажмите кнопку обновления расширения на странице расширений. Сначала остановите старый проход и сохраните нужный JSON. Прежние настройки API удаляются автоматически.
4. Нажмите значок расширения: откроется просторная вкладка сборщика. Повторное нажатие возвращает к ней. Вставьте ссылки по одной на строку; две карточки видеокарт уже указаны как пример.
5. Настройте паузу между страницами, ожидание загрузки и предел страниц. Нажмите «Начать» и разрешите доступ к выбранному маркетплейсу.
6. Расширение создаст одну фоновую вкладку и последовательно соберёт наблюдения. Вкладку управления можно закрыть; браузер должен оставаться запущенным.
7. Если включено автоматическое скачивание, JSON появится в папке загрузок по завершении. Кнопка экспорта сохраняет также промежуточный результат через «Сохранить как».

Чтобы прислать данные в чат без файла, нажмите «Показать JSON», затем «Скопировать JSON» и вставьте текст в сообщение. Кнопка показывает снимок на момент нажатия; чтобы получить новые данные во время сбора, нажмите «Обновить JSON». Можно скопировать текст вручную, если браузер не разрешил доступ к буферу обмена. Каждый профиль содержит свои результаты; при сборе несколькими профилями копируйте JSON из каждого отдельно.

Пауза и остановка прекращают автоматические переходы. Уже полученные записи сохраняются. После перезапуска браузера продолжение требует явного действия. Перед очисткой сохраните нужный JSON.

## Конфигурация в JSON

Блок «Конфигурация JSON» содержит редактируемые настройки запуска. Нажмите «Сформировать из настроек», чтобы получить их текст, и «Скопировать конфигурацию», чтобы отправить его в чат. Полученный обратно JSON можно вставить в это же поле и нажать «Применить JSON», затем «Начать сбор». Применение проверяет настройки и само сбор не запускает. Во время действующего или приостановленного запуска сначала остановите сбор.

Конфигурация и JSON результатов — разные документы. Конфигурация не содержит наблюдений и не восстанавливает незавершённый проход. Для десяти профилей передайте одну конфигурацию с `partition.count: 10`, задавая в каждом профиле свой `partition.index` от 1 до 10.

Пример конфигурации:

```json
{
  "schema_version": "cenoskop.collector-config.v1",
  "urls": ["https://www.ozon.ru/category/videokarty-15721/"],
  "settings": {
    "delaySeconds": 12,
    "renderWaitSeconds": 8,
    "pageTimeoutSeconds": 45,
    "maxPages": 110,
    "categoryScrollRounds": 12,
    "categoryScrollPauseSeconds": 2,
    "categoryMaxProducts": 100,
    "categoryMaxPages": 3,
    "autoExport": true
  },
  "partition": {"count": 10, "index": 1}
}
```

## Ссылки и категории

Поддерживаются карточки Ozon `/product/…-123/` и Wildberries `/catalog/123/detail.aspx`. Отслеживающие параметры удаляются, повторные карточки по одному SKU обходятся один раз.

Можно добавить категорию Ozon, например `https://www.ozon.ru/category/videokarty-15721/`. Сборщик читает карточки, прокручивает страницу примерно на один экран, ждёт подгрузки и повторяет чтение. Уже найденные ссылки сохраняются, даже если площадка убирает прежние карточки из DOM. Повторные SKU не добавляются.

По умолчанию: 12 прокруток на страницу, пауза 2 секунды для подгрузки, до 100 товаров на исходную категорию и до 3 страниц категории. Все пределы настраиваются. При явной ссылке «Далее» сборщик может открыть следующую страницу той же категории. Произвольные номера страниц и скрытые API не используются. Параметр `page` сохраняется; отслеживающие параметры и фильтры удаляются, поэтому пока используйте обычную ссылку категории.

Сканирование страницы завершается по лимиту либо после трёх проходов без роста у нижнего края. Если страницы растут, чтение продолжается до настроенного предела. Число найденных товаров и причина остановки видны в интерфейсе и JSON. Категория показывает только доступные браузеру карточки; полный каталог площадки не гарантируется.

Общий предел очереди включает товары и страницы категорий. При стандартном пределе 50 часть найденных товаров может не попасть в очередь. Для примерно 100 товаров задайте общий предел, например 110 (максимум 200); точное число зависит от числа исходных ссылок и страниц категорий. Увеличение ожидания подгрузки до 3–5 секунд помогает при медленном соединении.

Одна вкладка работает последовательно. Пауза — нижняя граница: браузер может задержать фоновые события. Короткий таймер дополнен сохраняемым расписанием и `chrome.alarms`; работа не зависит от открытой вкладки управления. Chrome/Edge 120+.

## Несколько браузеров

Нужны отдельные профили Chrome/Edge: обычные окна одного профиля разделяют состояние и не образуют независимые сборщики. В каждом профиле установите распакованное расширение, вставьте одинаковые исходные ссылки и настройки категории. В разделе параллельного сбора укажите, например, всего экземпляров 10 и уникальный номер от 1 до 10. Каждый профиль откроет свою вкладку сбора и сформирует собственный JSON с номером части; все файлы нужно импортировать на сайт.

Категории проверяются каждым профилем; найденные ссылки товаров распределяются по каноническому URL. Совпадение входных ссылок и настроек важно. Маркетплейс может показывать разные выдачи в разных профилях, поэтому полный охват не гарантирован. Это локальное разделение без общей очереди и без API, а не распределённая ферма с координацией. Каждый браузер должен оставаться запущенным; при CAPTCHA соответствующий проход остановится.

## Данные и JSON

Версия формата — `cenoskop.browser-export.v1`. Файл содержит сведения о запуске, настройки, наблюдения и ошибки. Подробности — в `export-format.md` и `export-schema.json`.

`example-export.json` показывает формат на двух ранее записанных фактических наблюдениях от 15 ноября 2026. Это пример преобразования снимка, а не результат нового автоматического запуска и не обещание актуальности цен.

Наблюдение включает источник, чистый URL, время, версию экстрактора, характеристики, ссылки на фотографии, агрегированный рейтинг и количество оценок/отзывов при наличии, цену и условия, ценовые варианты и признаки `needs_review` / `review_reasons`. Тексты отзывов не собираются.

- Конкретный JSON-LD Offer имеет приоритет, когда его можно связать с текущей карточкой.
- Банковская скидка, обычная цена и рассрочка не смешиваются.
- При неоднозначном выборе основная цена остаётся пустой, кандидаты сохраняются для проверки.
- Неизвестные регион, состояние, продавец, гарантия и характеристики не выдумываются. Автоматического объединения похожих моделей нет.
- `identity_confirmed` не становится истинным от автоматического сбора.
- Один обход даёт один замер, а не готовую историю. Отзывы и рейтинги не генерируются.

Файл не отправляется в API и не добавляется на сайт автоматически. На работающем сайте откройте «Импорт JSON» и выберите «Добавить в каталог сайта». Записи появятся как непроверенные карточки; сопоставление моделей остаётся отдельной стадией.

## Разрешения и ограничения

Доступ запрашивается только к площадкам из входного списка. Нет разрешений на произвольные сайты или API. `scripting`, `storage`, `alarms`, `downloads` нужны для чтения, очереди, расписания и JSON; `activeTab` — для действий с текущей страницей; `clipboardWrite` — для копирования JSON по нажатию кнопки. Расширение не читает буфер обмена.

Нет доступа к cookies, истории, прокси или перехвату запросов. HTML, файлы фотографий, описания и тексты отзывов не копируются; ссылки на изображения и агрегированный рейтинг сохраняются, если найдены. Расширение не отправляет содержимое страницы на сервер; открываемые страницы выполняют свои обычные сетевые запросы.

CAPTCHA или блокировка останавливает обход с сохранением частичных данных. Обходов ограничений, смены идентичности и бесконечных повторов нет. Ошибки страниц записываются в JSON. Условия источников перед публичным использованием проверяются отдельно.

## Проверки

Из корня проекта:

```powershell
node --check browser-extension/background.js
node --check browser-extension/collector-engine.js
node --check browser-extension/extractor.js
node --check browser-extension/popup.js
node --test browser-extension/extractor.test.cjs browser-extension/background.test.cjs browser-extension/dashboard.test.cjs browser-extension/popup.test.cjs browser-extension/package.test.cjs
```

Тесты используют локальные структуры страниц и модель Chrome API. Они не заменяют полный прогон установленного расширения на живом маркетплейсе; разметка может измениться.

Официальные сведения: [service worker](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle), [alarms](https://developer.chrome.com/docs/extensions/reference/api/alarms), [downloads](https://developer.chrome.com/docs/extensions/reference/api/downloads).
