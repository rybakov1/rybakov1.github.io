# Источники данных и права

Этот MVP по умолчанию работает на синтетических данных. Цены, продавцы, предложения, история и отзывы DemoProvider вымышлены. Бренды и модели используются как идентификаторы для демонстрации сравнения; изображения компонентов — собственные SVG. Ни одна демоцена не является текущим предложением Ozon или Wildberries. Детальные синтетические отзывы используются только внутри явно обозначенного деморежима.

## Подключение реального источника

`ImportProvider` обрабатывает переданный оператором CSV/JSON. Это парсер структурированного фида, а не краулер сайтов. Адаптеры Ozon/Wildberries по умолчанию отключены. Наличие публичного API, партнёрской программы, прав на сбор и повторную публикацию данных не предполагается. Недокументированные эндпоинты, обход CAPTCHA/блокировок, подмена личности и ротация прокси в MVP отсутствуют.

До подключения нужно получить разрешение на конкретный способ доступа и использования, зафиксировать источник, основание доступа, дату наблюдения, периодичность, ограничения хранения и публикации. Передача `permission` в импортёр — журнал заявления оператора, а не юридическая проверка договора программой. Оператор отвечает за действительность разрешения. Для внешних ссылок нужен явный список допустимых доменов; импорт не должен сам выполнять HTTP-запрос к URL из файла.

## Чек-лист для владельца и юриста

- Проверить применимые условия площадки/поставщика, договор/API-лицензию, территорию, срок, лимиты запросов, ограничения кеширования, коммерческого использования и публичного отображения.
- Проверить отдельно права на фактические данные (цены, наличие, характеристики), базы данных, фотографии, описания, товарные знаки, тексты и агрегаты отзывов. Разрешение читать API не обязательно разрешает копировать каждое поле.
- Не публиковать чужие изображения, описания и полные отзывы без необходимых прав. При отсутствии разрешения на детальные отзывы показывать «детальные отзывы недоступны»; отсутствие доступа не равно отсутствию отзывов.
- Уточнить право хранить историю после отзыва разрешения, порядок удаления и срок хранения. Записать контакт правообладателя и обработку запросов на исправление/удаление.
- Проверить правила показа продавца и площадки. Не ставить признаки «официальный магазин», «оригинал», «подтверждённая покупка» или гарантию без проверяемого поля источника.
- Использовать обычные ссылки. Партнёрские метки, утверждения о комиссии и рекламную маркировку подключать только после действующего соглашения и проверки требований применимой юрисдикции.
- Проверить обработку персональных данных, территорию хранения, обязанности оператора, уведомление о целях и сроках, удаление подписок и возможность реализации прав пользователя. Не хранить текст сообщений, IP и профиль Telegram без необходимости.
- Проверить домен через актуальный WHOIS/RDAP, реестр товарных знаков и поисковую выдачу. Доступность `cenoskop.ru` и альтернатив не проверялась; название — настраиваемое рабочее имя.
- Для публичного запуска опубликовать политику конфиденциальности, описание методики, контакты владельца и правила работы сервиса с учётом реально подключённых данных. Этот документ — инженерный чек-лист, не юридическое заключение.

## Прозрачность происхождения

У источника и импортируемых наблюдений хранится `data_provenance`: идентификатор источника, основание разрешения, время наблюдения, время импорта и признак демо. Не заменять время наблюдения временем импорта. История за 90 дней не даёт оснований для заявления «минимум за всё время».

## Минимизация и хранение

Telegram ID нужен только для доставки личных уведомлений и хранится зашифрованным ключом `TELEGRAM_ID_ENCRYPTION_KEY`; ключ не должен лежать рядом с резервной копией БД. Пользователь подтверждает подписку в боте и может её отменить. Значение `DATA_RETENTION_DAYS` задаёт срок хранения служебных событий/отключённых подписок; конкретное поведение очистки описано в коде worker. Историю цен и обезличенные агрегаты отделять от персональных данных. Политику хранения для производственного источника согласовать до его подключения.
