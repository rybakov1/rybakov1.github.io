# DiagDoc

Демонстрационная версия русскоязычного справочника автомобильной диагностики. Материалы имеют статус `needs_review` и явно обозначены на сайте. По решению владельца они открыты для индексации; необходимо проверить их по источникам и документации производителей.

## Запуск

Требуется Node.js 20.19+ (или совместимая версия) и npm.

```bash
npm install
npm run dev
```

Откройте адрес, указанный в терминале (обычно http://localhost:3000). Для проверки статической сборки: `npm run build`; результат находится в `out/`. Для публичного домена настройте `NEXT_PUBLIC_SITE_URL` перед сборкой.

## Устройство проекта

- Next.js App Router и TypeScript формируют статические страницы, метаданные, `robots.txt`, `sitemap.xml`, JSON-LD и страницу 404.
- Маршруты: `/`, `/codes/`, `/symptoms/`, `/dashboard/`, `/guides/` и страницы материалов внутри каждого раздела. Незаполненный раздел марок сознательно не опубликован.
- `src/data/content.ts` содержит демонстрационные структурированные записи. Поиск, фильтры и пагинация каталога работают в браузере без сервера; их состояние не создаёт индексируемые адреса.
- PostgreSQL, Prisma, Zod, импорт и поиск в базе подготовлены отдельно. Текущая статическая версия читает файлы, а не базу; для обновления статической сборки проверенные материалы экспортируются командой `npm run content:export`. См. [CONTENT.md](CONTENT.md).
- Общие компоненты: шапка и подвал, поиск, каталог, карточки, страница материала, хлебные крошки, SEO-функции и заготовка `AdSlot`. Реклама и аналитика не подключены.

## Дальнейшее развитие

1. Проверьте и дополните каждый материал с опорой на первоисточники; укажите `verificationStatus: "verified"`, `verifiedAt` и `status: "published"` только после проверки.
2. По мере проверки переводите записи в `published`, актуализируйте материалы и следите за картой сайта.
3. Настройте домен и проверьте canonical, 404, карту сайта, ссылки и доступность в реальной среде. Измерьте Core Web Vitals на реальных пользователях.
4. Перед подключением рекламы или аналитики обновите политику конфиденциальности и настройте согласия в соответствии с применимыми требованиями.

Показатели производительности, соответствие требованиям рекламной сети и техническая достоверность материалов не гарантируются текущим демо.
